# AI Tools Lab — Machine Exercise 3 (ME-3)

A hands-on laboratory repository demonstrating Git version control, branching strategies, collaborative Pull Request workflows, and AI-assisted programming and debugging.

## Course Information
- **Course:** AIT Lab
- **Course Code:** AGCS-25308

---

## Repository Structure & Overview

- `hello.py`: Initial Python script to verify local execution and Git commit/push workflows.
- `sorting.py`: Implementation of the Bubble Sort algorithm developed on the `feature/sorting` branch.
- `utils.py`: Modular utility functions (`is_palindrome`, `count_words`, `celsius_to_fahrenheit`) developed on the `feature/utils` branch.
- `Exercise 2/`: Contains debugging exercises, error reference sheets, code reviews, and multi-language algorithm conversions.
